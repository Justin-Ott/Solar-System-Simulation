## Group Members

## Project Description
A 3D interactive model of our solar system built with Three.js and WebGL. Features realistic planet textures, orbital mechanics, and interactive controls.

## Features Implemented
1. **Geometry Primitives**: Spheres for planets
2. **Phong Shading**: Realistic lighting 
3. **Interactions**: 
   - Camera controls (orbit, zoom, pan) WIP
   - Planet selection with info display WIP
4. **Imported 3D Model**: Spaceship model in GLTF format


## Controls WIP
- Left click + drag: Rotate view
- Right click + drag: Pan view
- Scroll: Zoom in/out
- WASD: Move camera
- Q/E: Zoom in/out
- R: Reset view
- Click planet: Show information
